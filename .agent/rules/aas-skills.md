Use installed Antigravity Awesome Skills (AAS) whenever relevant.

Before starting a major task:
1. Identify the most relevant installed skill.
2. Read and follow its instructions.
3. Briefly mention the selected skill.
4. Plan before implementing complex features.
5. Make small, testable changes.
6. Run relevant tests and report the results.

For Python projects, use a project-specific .venv and follow PEP 8.
Never invent unavailable skills, expose secrets, or install packages without approval.
